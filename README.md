# Les Mail 7.1

Easier Gmail / Yahoo / AOL connect with one-click App Password pages. Connected addresses become a dropdown to select and edit.

## Installers

| File | Use |
|---|---|
| `release/Les Mail-7.1.0-mac-arm64.dmg` | Apple Silicon |
| `release/Les Mail-7.1.0-mac-x64.dmg` | Intel Mac |
| `release/Les Mail-7.1.0-win-x64-Setup.exe` | Windows |

## Connect Gmail / Yahoo / AOL

1. Settings → Email accounts → Quick connect (Gmail / Yahoo / AOL)
2. Enter email + click **Open App Password page**
3. Create an app password, return to Les Mail, paste it, Test → Save
4. Synced new mail goes to **Screener**; Allow into LesBox when you want
