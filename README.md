# Envision Mail 2.5

Durable local data, MoneyBox $, New Senders, HTML signatures, read receipts.

## Installers

| File | Use |
|---|---|
| `release/Envision Mail-2.5.0-mac-arm64.dmg` | Apple Silicon |
| `release/Envision Mail-2.5.0-win-x64-Setup.exe` | Windows |

Data lives in `~/Library/Application Support/Envision Mail/envision-mail-state.json` and is kept across updates.
